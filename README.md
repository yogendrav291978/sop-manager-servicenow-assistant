# SOP Manager with ServiceNow Assistant

An AI Copilot built using Microsoft Copilot Studio for Beauty Clinics and Healthcare operations.  
It allows staff to:
- Access SOPs through natural conversation
- Raise IT/facility tickets via ServiceNow
- Fetch file links from SharePoint folders using chat

## 🚀 Features
- SOP Manager via Copilot Studio
- Ticket Raising in ServiceNow (via Power Automate)
- SharePoint Folder Link Fetcher
- Adaptive Cards for UI interaction
- Role-based SOP filtering

## 🛠️ Tech Stack
- Microsoft Copilot Studio (Power Virtual Agents)
- Power Automate
- SharePoint Online
- ServiceNow (REST API)
- Adaptive Cards

## 🧪 How to Set Up
1. Import Copilot bot into your Copilot Studio.
2. Configure Power Automate flows:
   - SharePoint folder file fetcher
   - ServiceNow ticket creation
3. Connect to ServiceNow via HTTP connector.
4. Set up adaptive cards for user inputs.
5. Test the full flow.
